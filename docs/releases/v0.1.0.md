# AI Token Efficiency Playbook v0.1.0

First tagged public release, published 2026-10-01. The July 2026 changelog entry is historical, untagged development information.

## Included

- **Guidance:** context hygiene, progressive retrieval, reversible compression, selective skill loading, minimum-necessary implementation, governed routing/fallback, and multi-agent handoff, monitoring and recovery practices.
- **Adapters:** instruction files for Codex/general agents, Claude Code, Gemini CLI, GitHub Copilot and Cursor, with an overwrite-protected installer and source-ref pinning.
- **Helpers:** context-size and token-estimation utilities, Markdown/local-link checks, token-hygiene checks and regression tests.
- **Templates:** routing decisions, provenance manifests, continuation/handoff records, retrieval/compression receipts and benchmark/observability measurement records.
- **Evaluation:** a fixed synthetic corpus and protocols for routing/fallback, orchestration, retrieval, compression, resource discovery, document conversion and minimum-necessary implementation.
- **Visual overview:** the original infographic with an accessible text companion, alongside practical examples and fixture-based case studies.

## Validation And Limits

Repository validation covers helper behavior, installer mappings, instruction hygiene and local Markdown links. It does **not** establish that a particular live client version discovers, prioritises or obeys an adapter; see the [compatibility matrix](https://github.com/ravinperera/ai-token-efficiency-playbook/blob/v0.1.0/docs/adapter-compatibility.md).

Benchmark documents define reproducible protocols, not completed model evaluations. Existing case-study counts describe their stated fixtures and estimation methods. No universal token, cost, quality or latency improvement is claimed.

Routing, orchestration, monitoring and recovery sections are operating guidance. This release does not implement a router, agent orchestrator, durable-memory service or automatic approval enforcement. It is not production certification and does not replace access controls, testing or required human review.
